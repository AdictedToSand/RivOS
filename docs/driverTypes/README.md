# What does this directory list?

This is a continuation of [The driver specification](../driver.md). It will mainly contain the specific things a driver of a certain type should expose.

* The name will reflect the type (E.G. the fs spec is in docs/driverTypes/fs.md)

* Types currently include:
    - I/O (currently unsupported on build)
    - Storage
    - Filesystem (fs)
